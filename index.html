下面这些都可以自己选，改动立刻生效并存在这台设备上，默认全部打开。
通用
只要人还停在本页面就不让屏幕休眠（计时中、暂停中都算）；切到别的标签页或最小化时自动放开， 回到本页面再自动接管。需要 Chrome / Edge 等支持屏幕常亮接口的浏览器。
计时中移动鼠标时，在屏幕上方浮出当前时间（精确到秒），停下 3 秒自动渐隐。
计时与提醒
标签页上实时显示「剩余时间 · 任务名」，暂停时变成「已暂停 · 任务名」。
时间到的时候让标签页标题在「⏰ 时间到！」和原标题之间闪烁（没有任何声音）。
下次打开自动回填上次填过的内容。
计时中每 5 秒在本地记一次进度，刷新页面、误关标签页或浏览器崩溃后能接着跑（最多丢几秒）。 关掉后主页只保留手动「暂存」的那一份。
历史与统计
「共 N 条 · 今日 X · 本周 X」与「累计 X」。
历史记录里的 GitHub 风格热力图（最近 18 周）和右上角连续天数徽章。
在「本次学习内容」里输入时，下拉提示用过的任务名（支持模糊匹配）。
性能与网络
在下一个 20 分钟节点到来前 90 秒先把下一张下好，到点切图零等待。关掉可以少占一点带宽。
停在主页没事做的时候，把 24 张背景图（约 7.4MB）慢慢缓存到本地。关掉可以省流量。
数据备份
先在下面选一次备份文件（比如放到网盘的同步文件夹里），之后每次保存都会把新记录 合并写进这同一个文件：同一个 id 只保留一条，不会重复也不会生成一堆副本， 换电脑时直接把这个文件拷过去用「导入备份」即可。
网页没有权限直接往某个磁盘路径写文件，所以需要你选一次、浏览器记住这个文件；想换位置点「更改文件」。 手动「暂存 / 不保存」不会写备份文件，只有真正保存成记录才会。
