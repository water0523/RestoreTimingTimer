# Background Fit Implementation Plan

**Goal:** 背景默认等比铺满屏幕，适应设备尺寸、窗口变化和网页缩放；保留流畅移动与切图，允许在设置中恢复原来的显示方式。本地验收后按用户后续授权推送。

**Architecture:** 复用现有双背景层、偏好存储和计时时间轴。默认用 background-size: cover 保持比例，以统一的 scale(1.2) 为左右移动留出空间，通过 translate3d 平移；保持两层同步。CSS 随容器尺寸适配，不用延迟的 resize 回调或宽高动画。关闭开关后恢复原来的 120% 120% 和 background-position 平移。

**Tech Stack:** 原生 HTML/CSS/JavaScript、localStorage、Node.js、隔离 Chromium 浏览器。

### Task 1: 背景显示与偏好

- 修改 index.html：计时容器裁切溢出；增加等比显示样式和 backgroundCover 默认开关；设置中说明裁切边缘和关闭后的行为。
- 平移改为默认 translate3d，保留暂停、恢复、40 秒相位与双层淡入同步；初始加载和切换设置都应用当前偏好，刷新后保留选择。
- 版本更新为 v1.5.1。本机副本基于已发布的 b965c7f。

### Task 2: 文档与验证

- 修改 README.md：记录新显示方式和开关位置。
- 实际浏览器验证横屏、宽屏、手机竖屏、平板、连续调整窗口以及页面缩放；计算截图中的圆形比例、背景覆盖范围，检查不露白边、暂停冻结、恢复和切图。
- 验证开关关闭、重新打开和刷新后的选择，运行现有回归测试并检查差异。
- 将效果截图与独立可打开的本地压缩包放入 outputs，供用户检查；收到推送授权后发布到 main。

### 验收结果

- 26 项原有回归检查通过。
- 桌面、宽屏、平板及手机横竖屏尺寸和 DPR 3 检查通过；Chrome 真实页面缩放 75%、100%、125%、150%、200% 下，圆形保持比例，五个平移位置均无空白或暗边。
- 24 张实际背景、连续调整窗口、暂停冻结与恢复、开关切换及刷新后保留选择均通过；没有浏览器运行错误。手机和平板采用浏览器设备模拟。
