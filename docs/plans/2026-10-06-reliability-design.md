# 计时器数据可靠性与导入设计

目标：修复审查列出的七个问题，只新增合并导入、导入预览、删除撤销；热力图和今日/本周合计按开始日期归属。增加 README 的 24 条图片来源与文案，以及设置中的全文案赏析链接。

采用现有单文件架构和弹窗样式，不引入运行时依赖。导入默认合并，同 ID 冲突默认保留本机，也可在预览中选择备份优先；保留原有覆盖导入选项。应用导入前完整校验，展示新增、重复、冲突和删除标记影响，写入失败回滚已写入的本地键。

删除状态永久保存在本地和备份中。删除与撤销都带时间戳，合并时较新状态优先，防止未授权或失败的备份重试复活记录。撤销支持当前页面内按最近删除顺序逐条恢复，刷新后撤销栈清空，删除标记仍保留。

固定备份文件按队列写入，并在支持时使用同源 Web Locks；权限申请在用户点击内启动。执行时读取最新本机数据和旧文件。空文件可初始化；读取、解析或校验失败停止写入，保留原文件。

新增记录保存 startedAt 时间戳，继续保留原有显示字段。旧记录解析中文年月日、年/月/日与常见英文格式；无法解析的开始时间不猜测，不纳入按日期统计，但仍计入累计并提示数量。整次专注归属开始日期，不按午夜拆分。

验证：原始失败案例、并发写入顺序、失败重试、撤销后再备份、坏数据拒绝、合并/覆盖预览、跨午夜与旧记录日期、缓存隔离、取消预加载、完成进度环，以及真实浏览器交互。先完成本地验收，再按用户后续授权推送。
