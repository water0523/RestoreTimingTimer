# Timer Reliability Implementation Plan

**Goal:** 修复七项 bug，新增安全导入和删除撤销，按开始日期统计，并补充文案资料与链接。

**Architecture:** 保留单文件网页；在 index.html 内增加备份校验、状态合并和提交辅助函数，复用现有弹窗。sw.js 使用应用专属缓存前缀；测试使用 Node 内置测试工具和浏览器交互验证。

**Tech Stack:** 原生 HTML/CSS/JavaScript、localStorage、File System Access、Service Worker、Node.js。

---

### Task 1: 建立可复跑回归测试
- 创建 tests/regression.test.cjs，加载真实内联脚本，用独立本地存储和 DOM 替身验证审查中的失败案例。
- 先执行失败用例，记录旧代码错误，不使用实际用户数据。

### Task 2: 数据与日期基础
- 修改 index.html：逐条校验备份数据，保存 startedAt，兼容旧时间格式，按开始日期统计，明确无法解析日期的展示。
- 增加失败回滚的本地提交函数与带时间戳的删除/恢复状态合并函数。
- 验证坏记录、数组统计、旧时间、跨日、失败回滚。

### Task 3: 安全备份、撤销与导入
- 修改 index.html：串行写备份，保留权限申请的点击上下文，坏文件不覆盖，删除标记持续保留，撤销恢复记录与标记。
- 增加导入预览弹窗，默认合并、本机冲突优先，提供备份优先及覆盖模式。
- 验证并发、权限失败后重试、坏备份保护、重复 ID、预览取消、合并和撤销后的再备份。

### Task 4: 其余修复与资料
- 修改 sw.js：专属缓存名和仅清理本应用旧缓存。
- 修改 index.html：取消请求不备用加载、完成环显示满圈、设置赏析链接、版本号。
- 修改 README.md：新行为、测试命令、24 条图片来源与文案。

### Task 5: 本地验收与交付
- 执行 Node 回归测试、真实浏览器导入预览/撤销/设置链接检查、git diff --check。
- 提供可双击使用的本地版本与压缩包；本地验收后按用户后续授权推送到 main。
